# Joyboy 🎮

Lern-Spiele-App für Kinder – spielerisch rechnen, lesen, merken und knobeln. Allein, gegen Robo, zusammen an einem Gerät oder mit bis zu 4 Kindern online, live synchron. Läuft als installierbare Web-App (PWA) auf iPhone, iPad und Android und wird über GitHub Pages veröffentlicht.

**Status:** Konzeptphase. Das vollständige Konzept mit Spiele-Katalog, Tutorial-, Mehrspieler- und Speicherkonzept steht in [`docs/KONZEPT.md`](docs/KONZEPT.md). Die Umsetzung beginnt nach Freigabe von Konzept und Designrichtung.
