# Joyboy 🎮

Lern-Spiele-App für Kinder von 4 bis 12 Jahren: spielerisch rechnen, lesen, die Uhr lernen, merken und knobeln. Allein, gegen den Computer-Freund **Robo**, mit bis zu 4 Kindern an einem Gerät – oder **online im Spielzimmer, jedes Kind an seinem eigenen Gerät, live synchron**. Joyboy läuft als Web-App im Browser und lässt sich auf iPhone, iPad und Android wie eine normale App auf den Home-Bildschirm legen.

**App öffnen:** https://amirhossin27-dev.github.io/Games/

## Was Joyboy kann

- **Profile ohne Konto:** Spielername (mit Namens-Würfel, z. B. „Flinker Fuchs“), Tier-Avatar, Lieblingsfarbe und Alter. Mehrere Kinder können sich ein Gerät teilen („Wer spielt?“).
- **26 Spiele**, davon 11 Lern- und Brettspiele für 1–4 Spieler und 15 Arcade-Spiele aus Arta.
- **Tutorials mit Joy:** Das Maskottchen erklärt jedes Spiel in 2–4 Schritten, liest alles vor (für 4–7-Jährige automatisch) und lässt bei den Lernspielen einen Probezug machen. Beim ersten Spielen startet das Tutorial von selbst, danach über das ?.
- **Joys eigene Stimme:** eine neuronale Stimme (Piper), die direkt auf dem Gerät rechnet – auf iPhone, Android und PC gleich. Zur Wahl stehen **Kerstin** (Frauenstimme) und **Thorsten** (Männerstimme), jeweils mit Hörprobe unter **Für Eltern → Stimme**. Die Stimme wird beim ersten Vorlesen einmal geladen (ca. 63 MB, am besten im WLAN) und funktioniert danach auch offline. Was vorgelesen wird, verlässt das Gerät nicht. Wer mag, kann dort auch eine Stimme vom Gerät wählen.
- **Mit dem Alter mitwachsen:** Das Alter wählt die passende Schwierigkeit (Leicht, Mittel, Schwer). Robo spielt je nach Stufe schwächer oder stärker.
- **Belohnungen:** Sterne (0–3 pro Spiel), Level, 9 Abzeichen, Rekorde, eine Tagesaufgabe und eine Wochen-Rangliste der Kinder auf dem Gerät.
- **Spielzeit-Limit für Eltern:** siehe unten.
- **Online-Spielzimmer** für bis zu 4 Kinder, mit **Freunden** und **Chat**, siehe unten.
- **Spielstände dauerhaft gesichert:** auf dem Gerät und zusätzlich in der Cloud. Mit dem **Spielerpass** (Elternbereich) nimmt ein Kind seinen Spielstand auf ein neues Gerät mit.
- **Kindersicher:** Chat nur mit den Kindern im eigenen Spielzimmer, mit Filter gegen Schimpfwörter, Telefonnummern, Adressen und Links – Eltern können ihn auf fertige Sätze beschränken oder abschalten. Keine Werbung, keine Käufe, keine Tracker. Schriften und Stimme werden mit der App ausgeliefert, kein Abruf bei Google. In der Cloud liegen nur Spitzname, Tier, Sterne und Spielstand.
- **App-Gefühl:** Texte lassen sich nicht markieren, langes Drücken öffnet kein „Kopieren / Nachschlagen“-Menü (außer in Eingabefeldern).

## Die Spiele

| Spiel | Lernziel | Spieler |
| --- | --- | --- |
| Rechen-Rallye | Plus und Minus bis 10, 20, 100 und Einmaleins, mit Zehnerfeldern als Zählhilfe | 1–4 |
| Buchstaben-Jagd | Anlaute, Bild zum Buchstaben, fehlender Buchstabe | 1–4 |
| Uhr-Profi | volle Stunden, halb, Viertel, Minuten | 1–4 |
| Paare finden | Gedächtnis | 1–4 |
| Vier gewinnt, Tic-Tac-Toe | Logik | 2 |
| Ludo | Zählen, Regeln, fair verlieren | 2–4 |
| Mau-Mau | Farben und Zahlen vergleichen | 2–4 |
| Würfelglück (Kniffel-Regeln) | Addieren, Entscheiden | 1–4 |
| Schiffe versenken | Koordinaten (z. B. C5) | 2 |
| Stadt-Land-Fluss | Wortschatz, Rechtschreibung | 2–4 |
| Arcade: Schlange, Klötzchen, 2048, Flatter-Vogel, Hüpfer, Mampfer, Mauer-Brecher, Tempel-Lauf, Weltraum-Abwehr, Ball-Blitz, Ton-Echo, Minen-Detektiv, Solitär | Reaktion, Raumvorstellung, Logik | 1 (Rekordjagd) |
| Pong-Duell, Blitz-Duell | Reaktion | 2 an einem Gerät oder gegen Robo |

Gegen Robo antworten in den Lernspielen alle gleichzeitig. Teilen sich mehrere Kinder ein Gerät, geht es reihum. Bei Spielen mit Geheimnissen (Mau-Mau, Schiffe versenken, Stadt-Land-Fluss) erscheint zwischen den Zügen ein Sichtschutz: „Gib das Gerät weiter – nicht spicken!“

## Online-Spielzimmer

1. Ein Kind tippt **Zimmer → Zimmer öffnen** (oder auf einer Spielseite „Online“) und wählt ein Spiel.
2. Es bekommt einen **Zimmer-Code aus vier Tieren**, z. B. „Fuchs, Panda, Schildkröte, Löwe“. Den sagt es laut oder teilt den Link.
3. Die anderen tippen **Zimmer → Code eingeben** und die vier Tiere – oder öffnen den Link – und **klingeln**.
4. Der Gastgeber lässt jedes Kind mit einem Tipp rein (**Klingel-Prinzip**) und kann freie Plätze mit Robo füllen.
5. Der Gastgeber startet, alle spielen auf ihrem Gerät. „Nochmal“ startet die nächste Runde für alle.

Online spielbar: Rechen-Rallye, Buchstaben-Jagd, Uhr-Profi, Paare finden, Vier gewinnt, Tic-Tac-Toe, Ludo, Mau-Mau, Würfelglück, Schiffe versenken und Stadt-Land-Fluss. Bei den Lernspielen und Stadt-Land-Fluss antworten alle gleichzeitig, sonst geht es reihum. Jedes Gerät sieht nur die eigenen Karten.

**Wenn etwas wegfällt:** Ist ein Kind länger als 20 Sekunden weg (App zu, kein Netz), spielt Robo seine Züge, bis es zurück ist. Fällt der Gastgeber aus, übernimmt automatisch ein anderes Gerät. Wird die App geschlossen, geht es beim nächsten Öffnen im Zimmer weiter.

### Freunde

Wer einmal zusammen online gespielt hat, wird **Freund** – ganz ohne Freundschaftsanfrage. Unter **Zimmer → Freunde** sieht jedes Kind, wer gerade online ist und wer schon in einem Spielzimmer wartet:

- **Einladen:** Spiel aussuchen, fertig. Der Freund bekommt in seiner App (egal auf welcher Seite) die Einladung „Mia lädt dich ein!“ und kommt mit einem Tipp auf **Mitspielen** rein.
- **Mitspielen:** Wartet ein Freund schon im Spielzimmer, reicht ein Tipp – kein Code, kein Klingeln.
- Freunde und Eingeladene lässt der Gastgeber automatisch rein. Alle anderen müssen weiter klingeln.
- Freunde stehen auch in der Wochen-Rangliste. Wer nicht mehr in der Liste stehen soll, lässt sich mit dem ✕ entfernen.

### Chat

Sobald mindestens zwei Kinder im Spielzimmer sind (nicht gegen Robo oder allein), gibt es einen Chat – im Wartezimmer als Karte, im laufenden Spiel über die Sprechblase oben (mit Zähler für neue Nachrichten). Es gibt fertige Sätze zum Antippen („Gut gemacht! 👍“, „Du bist dran!“ …) und ein Eingabefeld für eigene Nachrichten (höchstens 80 Zeichen). Ein Filter blockt Schimpfwörter, Telefonnummern, E-Mails, Links und Adressen – auch beim Empfangen. Die Reaktionen (Daumen, Lachen, Staunen, Juhu, Super) gibt es weiterhin.

Technik: Firebase Realtime Database über REST und Server-Sent Events (kein SDK) und anonyme Anmeldung pro Kind. Der Gastgeber rechnet mit denselben Regel-Funktionen wie offline und veröffentlicht jeden Stand; die anderen schicken nur ihre Züge und Chat-Nachrichten (im eigenen Platz). Ob ein Freund online ist, steht in seinem öffentlichen Profil (`on`, `room`); Einladungen stehen im Zimmer (`info/invited`). Regeln: [`database.rules.json`](database.rules.json), Einrichtung: [`docs/FIREBASE.md`](docs/FIREBASE.md).

## Spielzeit-Limit (für Eltern)

1. In der App auf **Ich → Für Eltern** tippen und beim ersten Mal ein Passwort festlegen. Dabei zeigt Joyboy einmalig einen **Notfall-Code**, falls das Passwort vergessen wird.
2. Unter **Spielzeit** ein Limit wählen: 15, 30, 45, 60, 90 oder 120 Minuten.
3. Die Restzeit steht oben in der App. Bei 5 und bei 1 Minute erinnert Joy.
4. Ist die Zeit aufgebraucht, macht Joyboy **12 Stunden Pause**. Ein Countdown zeigt, wann es weitergeht.
5. Eltern können mit dem Passwort jederzeit **15 Minuten schenken**, die **Sperre aufheben** oder das Limit ausschalten.

Ebenfalls im Elternbereich: **Vorlesen** (automatisch bis 7 Jahre, immer, aus), **Stimme** (Kerstin, Thorsten oder eine Stimme vom Gerät), **Chat im Spielzimmer** (schreiben mit Filter, nur fertige Sätze, aus) und der **Spielerpass**.

Gezählt wird, solange Joyboy sichtbar geöffnet ist (nicht im Elternbereich). Das Kontingent gilt für 12 Stunden ab dem ersten Spielen. Damit das Verstellen der Geräte-Uhr nicht hilft, gleicht Joyboy die Zeit mit dem Server ab, sobald Internet da ist. Das Passwort wird nur als Hash gespeichert (PBKDF2).

> Grenzen: Das Limit gilt pro Gerät. Löscht jemand die Website-Daten im Browser, ist es weg (die Spielstände lassen sich über den Spielerpass zurückholen). Am sichersten ist es zusätzlich, die Bildschirmzeit-Funktionen von iOS bzw. Android zu nutzen.

## Auf dem Handy installieren

- **iPhone/iPad (Safari):** Link öffnen → Teilen-Symbol → „Zum Home-Bildschirm“
- **Android (Chrome):** Link öffnen → Menü ⋮ → „App installieren“

Nach dem ersten Öffnen funktioniert Joyboy auch offline.

## Entwicklung

Voraussetzung: Node.js ab Version 20.

```bash
npm install
npm run dev
```

| Befehl | Zweck |
| --- | --- |
| `npm test` | Tests ausführen (Vitest) |
| `npm run build` | Typecheck und fertige App nach `dist/` |
| `npm run preview` | Gebaute App lokal ansehen |
| `npm run voices` | Joys Stimmen (je 63 MB) nach `public/voice/models` laden – einmal, für lokales Testen |

Jeder Push auf `main` oder den Entwicklungs-Branch testet, baut und veröffentlicht die App über GitHub Actions auf GitHub Pages. Die Stimm-Modelle liegen nicht im Git: Der Workflow lädt sie mit fester Version und Prüfsumme von [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) und hält sie im Actions-Cache.

### Aufbau

```
src/
  engine/   Spiele-Engine für 1–4 Plätze (useGame, auch online), Robo, Tutorial-Typen
  net/      Firebase: Anmeldung, REST/Live-Stream, Cloud-Spielstände, Spielzimmer, Freunde
  voice/    Joys eigene Stimme: Worker mit eSpeak NG (nur Deutsch) + Piper über onnxruntime-web
  learn/    Aufgaben-Generatoren und Lernspiel-Engine
  games/    Spielekatalog, Regeln (rules/) und Ansichten (views/)
  arcade/   Arcade-Spiele aus Arta (fast unverändert übernommen)
  lib/      Speicher, Spielzeit, Eltern-Passwort, Vorlesen, Fortschritt, Navigation
  ui/       Avatare, Joy, Spiel-Illustrationen, Icons, Bausteine
  screens/  Willkommen, Start, Spiel-Seite, Spiel, Tutorial, Ich, Eltern
```

Konzept und Plan: [`docs/KONZEPT.md`](docs/KONZEPT.md).
